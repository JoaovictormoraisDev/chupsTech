# Backend

API do Equilibrio Digital, responsavel pelas regras de negocio, persistencia em JSON e endpoints usados pelo front-end.

## Rodar

```bash
npm start
```

## Pastas

- `src/config/`: leitura e escrita do banco JSON.
- `src/controllers/`: controle das requisicoes HTTP.
- `src/routes/`: roteamento da API.
- `src/services/`: regras de negocio e validacoes.
- `database/`: arquivo `db.json` com os dados persistidos.
